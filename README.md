🧠 What You’ll Find in This Project
🔍 Supplier Comparison
Evaluate multiple suppliers for each part based on unit cost, volume, and non-recurring expenses.

⚖️ Make vs Buy Analysis
Use scenario planning to weigh in-house manufacturing costs (including investment) against supplier offers.

📊 Visual-First Reporting
Dynamic charts reveal cost breakdowns, capacity gaps, and opportunities for cost avoidance.

💰 Cost Avoidance Insights
Quantify how much money the company can save by choosing the optimal path for each product.

🚀 Key Features
Scenario Planner to simulate buying at various volumes.

Capital Investment Analysis for internal manufacturing.

Interactive Visuals built in Power BI for quick insight.

Supplier Ranking based on cost efficiency and reliability.

🛠 Tools Used
🟦 Microsoft Power BI

📁 Excel (for underlying data)

📐 Business Logic: TCO (Total Cost of Ownership), CAPEX vs OPEX

✅ Final Outcome
The final report enables decision-makers to:

Clearly identify the lowest-cost sourcing strategy per part.

Balance short-term savings with long-term investments.

Justify decisions with interactive visual storytelling.
